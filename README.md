# Fractal Tree Drawing
This project visualizes a fractal tree using HTML5 <canvas> and JavaScript, with animations that simulate the growth of branches, the effect of wind, and the transition between 2D and 3D perspectives using math tricks (no actual 3D rendering).

## Features
### Grow Animation
Gradually adds new branches to the tree, simulating the tree's growth.
### Wind Animation
Makes the tree sway as if it is being affected by wind, and transitions the tree from a 2D look to a simulated 3D effect using perspective tricks.
### Stop Wind Animation 
Stops the wind effect and transitions the tree back to its original 2D state.
